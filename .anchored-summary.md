## Goal
- Switch all AI agent chat and code generation from exhausted external APIs to the free opencode CLI (`opencode/deepseek-v4-flash-free`) running inside the Docker backend container.

## Constraints & Preferences
- Agents must respond only via AI, no hardcoded fallback text
- Only code execution from explicit imperative verbs (`değiştir`, `yap`, `ekle`, `sil`, etc.)
- Code blocks and emojis stripped from AI responses before TTS/display
- When user mentions an agent name, only that agent should speak (routing must check ALL agents, not just current room)
- Frontend serves from Docker image's built `dist/`; source changes require `docker compose up -d --build frontend`
- All three previous AI providers are exhausted: Gemini (429 quota), Groq (429 rate limit), OpenRouter/DeepSeek (zero balance)
- opencode CLI edits files directly as a side effect (`--dangerously-skip-permissions`); C# code must re-read from disk after call

## Key Decisions
- Use `opencode run` subprocess calls instead of HTTP POST to third-party APIs — eliminates all API-key dependency and cost
- Pass prompt via stdin (not escaped command-line args) to avoid shell quoting issues with long file contents
- After opencode call, re-read file from disk instead of parsing AI response text — opencode edits files directly as a side effect; text response is unreliable
- `routeMessage()` uses `allAgentIds` for name matching — so `"Cem ..."` works from any room, not just engineering
- OpenRouter/Gemini/Groq code paths removed entirely since they're all exhausted and opencode CLI handles everything
- `stopCmds` use `\b` word boundary to prevent "kes" matching "kesinlikle"
- `TargetFile` parsed from command text based on keywords (backend, frontend, api, etc.)
